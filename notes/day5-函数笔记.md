# Day5 Python函数学习
## 一、函数的定义与调用
- 定义语法：def 函数名(参数):
              函数体
              return 返回值（可选）
- 调用：函数名(参数)
- 示例：def add(a, b): return a+b → add(1,2) → 结果3

## 二、参数类型
1. 位置参数：按顺序传参 → add(1,2)
2. 关键字参数：按名称传参 → add(a=1, b=2)
3. 默认参数：def add(a, b=0): → 不传b时默认0

## 三、无返回值/有返回值函数
- 无返回值：函数只执行操作（如print），默认返回None
- 有返回值：用return返回结果，可赋值给变量
